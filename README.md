# Замена GUID в XML-выгрузке 1С

Веб-приложение для замены GUID в XML-файлах выгрузки 1С с автоматической синхронизацией справочников через HTTP-сервис.

## Возможности

- **Загрузка и парсинг XML** – извлечение всех объектов метаданных.
- **Синхронизация с 1С** – получение актуальных GUID из базы 1С через HTTP-сервис.
- **Автоматическая замена GUID** – по совпадению типа и наименования объекта.
- **Генерация изменённого XML** – с сохранением исходной структуры, пробелов и пространств имён.
- **Кодировка UTF-8 with BOM** – совместимость с 1С.

## Требования

- Python 3.8+
- Доступ к HTTP-сервису 1С (Basic Auth)
- Установленные зависимости (см. `requirements.txt`)

## Установка

1. Клонируйте или скопируйте проект в нужную директорию.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе `.env.example` и укажите:
   - `MCP_USER` – логин для Basic Auth
   - `MCP_PASSWORD` – пароль
   - `MCP_QUERY_URL` – URL HTTP-сервиса 1С (например, `http://erp-700/Vysotskaya_TA/hs/mcp-1c/query`)

## Запуск

```bash
python3 app.py
```

После запуска сервер будет доступен по адресу `http://127.0.0.1:5000`.

## Использование

1. **Загрузите XML-файл** (кнопка «Загрузить»).
2. **Синхронизируйте базу GUID** (вкладка «База GUID (1С)» → кнопка «Синхронизировать»).
   - Наблюдайте за прогрессом в реальном времени.
3. **Выполните автозамену GUID** (вкладка «Объекты из XML» → кнопка «Автозамена GUID»).
4. **Скачайте изменённый XML** (кнопка «Скачать XML»).
   - Файл будет сохранён с суффиксом `_modified` в кодировке UTF-8 with BOM.

## Устранение ошибок

### Ошибка XDTO при загрузке в 1С
- Убедитесь, что установлен `lxml`.
- Проверьте, что файл сохранён в кодировке UTF-8 with BOM (используется автоматически).
- Если ошибка сохраняется, попробуйте загрузить файл через другой XML-редактор (например, Notepad++) и сохранить с BOM.

### Ошибка подключения к 1С
- Проверьте доступность URL, указанного в `MCP_QUERY_URL`.
- Убедитесь, что логин и пароль верны.
- Проверьте, что HTTP-сервис 1С опубликован и работает.

## Технологии

- **Flask** – веб-фреймворк.
- **lxml** – парсинг и генерация XML с сохранением структуры.
- **SQLite** – локальное хранение GUID.
- **Server-Sent Events (SSE)** – потоковый прогресс синхронизации.

## Примечания

- При автозамене GUID используются поля `_type` (тип объекта) и `Description` (наименование) из XML.
- Если в базе данных нет записи с таким типом и наименованием, GUID не заменяется.
- Все изменения сохраняются в памяти до момента скачивания файла.
